# AthenaBot Plugin Template

Welcome to the official **AthenaBot Plugin Template**! This template provides a foundation for creating custom plugins for AthenaBot.

## 📋 Overview

This template includes pre-configured directories and example files to help you quickly get started with plugin development for AthenaBot. It follows best practices and the official plugin structure required by AthenaBot.

## 📚 Documentation

Our documentation can be found under the "Wiki" tab here on [GitHub](https://github.com/Zeroknights16/AthenaBot-PluginTemplate/wiki).

## 📁 Project Structure

```yaml
├── data/
│   ├── configs/          # Configuration files
│   └── dashboard/        # Dashboard config editor schema files
├── src/
│   ├── commands/         # Bot commands
│   ├── dashboard/        # Dashboard addon pages/components/api
│   ├── events/           # Event handlers
│   ├── handler/          # Custom handlers
│   ├── models/           # Data models
│   ├── routes/           # API routes
│   └── schedules/        # Scheduled tasks
└──  main.js              # Entry point
```
